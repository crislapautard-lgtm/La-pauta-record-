
# LaPauta Capture Studio

Grabador de pantalla para Windows 64 bits.

## Características

- Captura de escritorio completo.
- Grabación de audio del sistema.
- Grabación de micrófono.
- Vídeo MP4.
- Resoluciones 720p y 1080p.
- Velocidades de 8, 15 y 30 FPS.
- Interfaz oscura profesional.
- Compilación automática mediante GitHub Actions.

## Configuración predeterminada

- Resolución: 1280x720.
- Velocidad: 8 FPS.
- Codificación: H.264.
- Audio: 48 kHz.

## Compilación

GitHub Actions compila automáticamente
el programa para Windows 64 bits.

Los archivos se encuentran en Actions,
en la sección Artifacts.
